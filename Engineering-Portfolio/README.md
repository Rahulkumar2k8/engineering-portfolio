# Rahul Kumar — Engineering Portfolio

This repository contains the static HTML portfolio website.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `engineering-portfolio`.
2. Upload the contents of this folder to the repository root (especially `index.html`).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the deployment to finish in the Actions tab.

The site uses Tailwind CSS via its CDN and Google Fonts, so those external services need internet access in the visitor's browser.

## Custom domain
After you purchase a domain, configure it under **Settings → Pages → Custom domain** and add the DNS records GitHub provides. Do not add a `CNAME` file until you have chosen the exact domain.
